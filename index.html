01 — 结论先行

先说结论：升级是真的，「无法验证」也是真的

把舆论里混在一起的四种声音拆开 —— 每一种的可信度完全不同。

✓ 可确证 来自官方元数据 / changelog
原生多模态并入基座 —— 2.0 时代图像/视频是独立开源仓库，2.5 把视觉直接接进主模型
API 双协议 —— 同时提供 OpenAI 与 Anthropic 兼容端点，Claude Code 等工具可直连
工作面从终端扩到桌面 —— 浏览器、表格、设计工具被写进定位说明
老用户一次性发放 500 万 token，限时价与 2.0 促销价完全一致
◐ 厂商声称 美团口径，无第三方复现
?编码能力进一步提升 —— 措辞是「生成更稳、理解更细」，没有任何数字支撑
?长程任务能力 —— 「长」是新词，但没有长上下文召回率、没有轨迹长度指标
?参数量 1.6T / 48B —— 来自站点元数据与媒体转述，非 API 文档，且与 2.0 完全同数，疑似沿用
?限时价可改两次 —— 合同上写着，价格锚点随时会动

这次发布最反常的地方，不是参数，是「什么都没有附带」

2.0 发布时带着 9 项基准成绩、MIT 协议、HuggingFace 全量权重、INT8 分片、5 万张国产卡的训练记录； 2.5-Preview 到今天（发布第 3 天）没有模型卡、没有技术报告、没有基准表、没有权重、没有 GGUF、没有第三方评测， 美团 HuggingFace 组织下也没有对应仓库。同期 GLM-5.2 有独立评测的上下文召回分数 78.33，Qwen3.8-Max 有 Artificial Analysis 的完整榜单快照。 规格表和测试结果是两种不同的事实 —— 这一页在每一条数据上都标注了它属于哪一种。

关键洞察 01

价格没降。2.5 的限时价和 2.0 的限时价是同一组数字，且合同上写着还能改两次 —— 这次升级的账，全押在「多模态和长程任务值这个价」上，而不是靠便宜取胜。

关键洞察 02

参数完全没动。三代之间 1.6T/48B 一直没变，说明这轮升级主要发生在后训练与数据侧，而不是把模型做大 —— 这也解释了为什么它敢叫「Preview」。

关键洞察 03

最大的一处变化不在能力表里，在「怎么拿到」这一列：从 MIT 全量权重，退回到一个不能自部署、不能验证、限时可改价的预览端点。

09 — 选型建议

三种人，三个不同的答案

同一款模型，对三类使用者的正确选择是完全相反的。

FOR · 自部署 / 私有化

继续用 2.0

2.5 没有给你任何可下载的权重，也没有评测，你的选择其实只有两个：等，或者拿 2.0 的 MIT 权重自己去接多模态方案。2.0 的编码与长上下文能力是已验证的，且能跑在自己的国产卡上。

LongCat-2.0 · MIT · 自部署
FOR · 想尝鲜 / 做 GUI Agent

拿 500 万赠量去试

如果你的场景真的需要「读截图 + 长程操作桌面」，2.5 是目前唯一一个把这条链路写进定位说明的国产模型，且限时价与 2.0 相同、双协议兼容。用赠量跑真实任务，自己测出它值不值，别看通稿。
