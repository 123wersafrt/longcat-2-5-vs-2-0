# 龙猫 2.5-Preview vs 2.0

美团 **LongCat-2.5-Preview** 与 **LongCat-2.0** 的深度对比页。单文件静态页面，零外部依赖，全部视觉由内联 SVG / CSS / JS 手绘。

**在线地址：** https://123wersafrt.github.io/longcat-2-5-vs-2-0/

## 这一页想说什么

两代模型的规格表**逐行持平**（1.6T MoE / 约 48B 激活 / 1M 上下文 / 131,072 输出），价格**完全相同**，页面上的能力雷达**有增无减**——但 2.5-Preview 没有基准表、没有权重、没有模型卡。

所以这一页的选题不是「升级了多少」，而是**「一次无法验证的升级」**：把官方 changelog、厂商自报、第三方转述、页面推断四种证据分级摊开，让读者自己判断哪些是真变化、哪些只是话术。

## 设计

- 冷灰数据底 `#0b0d10` + 单一强调色琥珀 `#f0b429`
- 该强调色与 LongCat 官方品牌色一致（事后核对发现）
- 视觉元素：官方标识路径复刻的**分层猫**（躯干/尾/爪/头独立动画）、四幅手绘 SVG 线稿场景
- 三态状态模型：金框（支持）/ 橙斜纹（半支持）/ 红斜纹（不支持）
